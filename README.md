# Проект "Динамическое управление памятью и операции с матрицами"

Этот проект включает несколько заданий, направленных на освоение динамического выделения памяти, операций с матрицами и предотвращения утечек памяти в языке C:

## Задания

1. **Динамическое выделение памяти для массива**  
   Программа принимает длину массива `n`, выделяет память под массив динамически с помощью `malloc` или `calloc`, и сортирует его. В случае ошибки выводится "n/a" без символа новой строки.

2. **Предотвращение утечек памяти**  
   Программа, аналогичная предыдущей, но без утечек памяти. Если утечек не было, программа просто копирует исходную программу.

3. **Операции с матрицами и динамическое выделение памяти**  
   Программа позволяет пользователю выбрать метод выделения памяти для целочисленных матриц (статический и 3 динамических) через меню. После ввода данных программа выводит матрицу и очищает память.

4. **Поиск максимума в строках и минимума в столбцах**  
   Программа находит максимальные элементы в каждой строке и минимальные элементы в каждом столбце матрицы, а затем выводит их после матрицы.

5. **Отображение картинки в терминале**  
   Программа рисует картинку, используя статические массивы и матрицы, заданные в коде.

6. **Сортировка матрицы по сумме элементов строк**  
   Программа сортирует строки матрицы по возрастанию суммы элементов в каждой строке.

7. **Матрицы: операции сложения, умножения и транспонирования**  
   Программа выполняет одну из операций с матрицами: сложение, умножение или транспонирование, в зависимости от выбора пользователя.

8. **Решение задачи и сохранение в файл**  
   Программа решает задачу и сохраняет результат в файл `src/key10.txt`.

9. **Сортировка матрицы по сумме элементов строк**  
   Программа сортирует матрицу по возрастанию суммы элементов строк, после чего выводит отсортированную матрицу.
